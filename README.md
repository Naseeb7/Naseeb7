## A few things I've built

### 🎮 Nakama Authoritative Tic-Tac-Toe

I wanted to understand what happens when the server — not the browser — is responsible for deciding whether a multiplayer move is valid.

So I built one.

The result is a server-authoritative multiplayer system with gameplay validation, matchmaking, realtime synchronization, reconnect recovery, persistent match history and leaderboards, backed by Nakama and WebSockets.

**Next.js · React · TypeScript · Nakama · WebSockets · Docker · Railway**

[Repository](https://github.com/Naseeb7/nakama-authoritative-tictactoe)

### 📹 iSee

A peer-to-peer video communication platform built around WebRTC and Socket.IO.

It handles video calling, messaging, rooms and signaling, with the interesting problems being less about rendering a video element and more about keeping connections, sessions and participants in sync.

**React · Node.js · WebRTC · Socket.IO · MongoDB**

[Repository](https://github.com/Naseeb7/iSee-client)

### ✍️ Gatsby Blog Platform

A publishing platform I built from scratch with a custom Markdown editor, autosave, Git-based publishing and automated deployment.

I spent a lot of time on the less glamorous parts too — SEO, static generation, caching and build performance. It ended up contributing roughly 70% of the company's website traffic through organic discoverability. fileciteturn21file0L27-L33

## How I got here

I didn't start out as a "frontend product engineer."

I started by learning enough to build things, then kept moving closer to the parts of software that interested me: how products are structured, how systems communicate, how users experience them, and what it takes to keep everything working after deployment.

At Hexadecimal Software, my responsibilities grew from feature development into architecture, production engineering, mobile releases, emergency hotfixes, payment integrations, deep linking, AI-assisted features and realtime functionality. I worked closely with product, design and QA, mentored developers, and eventually became Team Lead. fileciteturn21file0L13-L26

That experience shaped how I approach engineering now: **don't just make the feature work — understand what you're shipping.**
